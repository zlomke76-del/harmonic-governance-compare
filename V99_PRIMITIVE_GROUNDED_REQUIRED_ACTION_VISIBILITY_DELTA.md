# V99 Governance Visibility Upgrade — Primitive-Grounded Required Action

This is a governance visibility upgrade only. It does not alter Harmonic primitives, admissibility semantics, or constitutional responsibility.

## Change
The harness Required Action projection now derives remediation only from primitives Harmonic actually returned as FAIL.

- Reality Contact FAIL -> request attributable present-state evidence.
- Authority Continuity FAIL -> request current authority source/scope/chain/verification/revocation evidence; does not claim authority transferred or changed.
- Obligation Continuity FAIL -> request resolution/re-establishment of the failed prerequisite/prohibition state.
- Consequence Boundary FAIL -> request establishment of requested action and downstream binding consequence surface.
- Runtime Admissibility FAIL -> no duplicate invented remediation; it remains the aggregate constitutional result.
- BLOCK always requires a new packet/reevaluation and never converts the historical blocked determination into permission.

The projection no longer emits generic authority-transfer or operator-review instructions unless established by the returned governance state.
